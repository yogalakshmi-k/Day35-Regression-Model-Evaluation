# Day 35 – Regression Model Evaluation

## Project Overview
This project evaluates a Linear Regression model using Python and Scikit-learn.

## Objective
To understand regression model evaluation metrics and measure prediction errors using MAE and MSE.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Implementation
1. Created a Salary vs Experience dataset.
2. Separated features and target variables.
3. Applied Train-Test Split.
4. Trained a Linear Regression model.
5. Generated predictions.
6. Calculated Mean Absolute Error (MAE).
7. Calculated Mean Squared Error (MSE).
8. Compared actual and predicted values.
9. Visualized the results.

## Results
- MAE: 409.29
- MSE: 205025.78

## Conclusion
Successfully evaluated a Linear Regression model using MAE and MSE. This task helped me understand how to measure prediction errors and interpret model performance.
